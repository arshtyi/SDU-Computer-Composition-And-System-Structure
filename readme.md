## Note

课程实验未进行到时评测数据都是旧的,进行到某实验时其数据才被更新(甚至可能是之后?).但本仓库大多数都实现于更新前

- 课程实验
  - Vivado: 2025.2
  - 把所有可能需要用到的文件都上传了,这是因为给的文件不一定是对的,甚至可能落后好几个版本(尤其是实验手册,给出的指导非常少不说,还有很多诸如管脚绑定这样的错误,有些时候只能从评测结果去推测,但是评测机也不一定是对的)
    - 关于实验手册:平台给的实验手册几乎是完全无用的(其包含了管脚绑定在内的一系列错误或过时内容).但其实课程还另外发了一份总手册(第一次发的甚至是其word被拆包后的xml),这份手册内容要更加有用一些(其管脚绑定也几乎都是正确的)
    - 进一步对比二者内容的话个人推测是:平台上给出的各个实验自己的手册应该是把总的这份导出为图片分别封好的(并且可能是因为过时或者单纯~~sb~~手滑,部分手册用了错误的内容).这个推测肯定不完全正确因为二者格式有明显差异(或许不是同一版本?这个可能性不小),但二者之间肯定存在没有经过大脑的CV(比如几幅Vivado的截图几乎都是复用)
  - 实验平台有玄学事件,选择50-100号板子有概率避免
