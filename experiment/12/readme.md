# Note

- 制作ROM类似lab9,手动 set as top
- 管脚:下排1-EKEY,2-AKEY,3-SKEY.上排8-5INTR,4-1MASK,RST复位
- 预期:
  - INTR=0001,MASK=0000,EKEY=1,SKEY010,AKEY010: LED1
  - INTR=0101,MASK=0000,EKEY=1,SKEY010,AKEY010: LED1
  - INTR=0101,MASK=0001,EKEY=1,SKEY010,AKEY010: LED3
  - INTR=0001,MASK=0000,EKEY=0,SKEY010,AKEY010: none;EKEY=1,SKEY010,AKEY010: LED1
