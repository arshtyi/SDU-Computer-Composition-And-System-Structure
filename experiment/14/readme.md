# Note

- 制作rom类似lab9
- 4 bit.(写的时候忘了手册是8bit,但是也过了)
- 管脚:CLK,LED4-1
- 微指令:

    | # | 含义 |
    | :---: | :--- |
    | `[15:8]` | 立即数 `a7..a0` |
    | `[7]` | `C0` |
    | `[6]` | `CPR0` |
    | `[5]` | `CPR1` |
    | `[4]` | `CPR2` |
    | `[3]` | `LM`,左移 |
    | `[2]` | `DM`,直通 |
    | `[1]` | `RM`,右移 |
    | `[0]` | `K`,减法控制 |

  - 应当取得$K=C0$
- 控制字:

    | 操作 | 微指令 | 说明 |
    | :--- | :---: | :--- |
    | `0xAA -> R0` | `00AA40` | 只置 `CPR0` |
    | `0x55 -> R1` | `005520` | 只置 `CPR1` |
    | `R0 + R1 -> R2` | `000014` | `CPR2 + DM` |
    | `2 * (R0 + R1) -> R2` | `000018` | `CPR2 + LM` |
    | `1/2 * (R0 + R1) -> R2` | `000012` | `CPR2 + RM` |
    | `R0 - R1 -> R2` | `000095` | `C0 + CPR2 + DM + K` |

- 预期

    | CLK | 微指令 | 结果 |
    | :---: | :---: | --- |
    | 2 | `00AA40`: `R0 <- A` |  |
    | 3 | `005520`: `R1 <- 5` |  |
    | 4 | `000014`: `R2 <- A + 5` | `F` |
    | 5 | `000018`: `R2 <- (A + 5) << 1` | `E` |
    | 6 | `000012`: `R2 <- (A + 5) >> 1` | `7` |
    | 7 | `000095`: `R2 <- A - 5` | `5` |
